# Abhishek & Ayushi – Wedding Invitation

A static site: no build step, no dependencies.

## Put it online with Vercel
1. Create a new GitHub repository and upload everything in this folder (index.html, invite.ics, README.md, and music.mp3 if you add one).
2. On vercel.com choose Add New → Project, import that repository, and press Deploy. Leave every setting at its default.
3. Share the .vercel.app link on WhatsApp.

## Music
Drop any song into this folder named `music.mp3` and it plays when the envelope opens. With no file, a built-in shehnai-style tune plays instead. Guests can mute it with the speaker button.

## Editing details
All text is in index.html. The event times are in the `E` list near the bottom, and the countdown target is the `T` line. The calendar file is invite.ics.
